# CodeAlpha Stock Portfolio Tracker

A simple stock tracker developed in Python as part of the CodeAlpha Python Programming Internship.

## Project Scope
- User inputs stock names and quantity.
- Uses a predefined dictionary of stock prices.
- Calculates and displays total investment value with itemized subtotals.
- Automatically formats an investment report for export.

## Key Concepts Used
- Dictionaries (`key: value` pairs)
- User input handling and boundary validation
- Basic arithmetic operations
- File handling logic

## How to Run
```bash
python portfolio_tracker.py
